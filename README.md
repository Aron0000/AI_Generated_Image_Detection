# AI_Generated_Image_Detection

[English](README.md) | [简体中文](README_zh.md)

A detection framework for AI-generated images that generalizes to **image generators never seen during training**.

The core method, **DELP**, extracts features with frozen CLIP ViT-L/14 and DINOv2 ViT-L/14 encoders, L2-normalizes each block, concatenates them, and fits a logistic-regression probe with only **1,793 parameters**. On the Unbiased Tiny GenImage benchmark (23,328 images across 7 generators), it reaches **95.9%** accuracy on unseen generators, compared with 69.4% for a frozen CLIP detector, 82.8% for ResNet-18, and 94.1% for UnivFD.

This repository contains the runnable code (`Code/`). The dataset, feature caches, model weights, results, and generated figures are not included — they must be prepared separately or regenerated by the scripts.

## 1. Repository layout

| Path | Description | Included |
| --- | --- | --- |
| `Code/` | All Python entry points and `src/` (data splits, model, training engine) | Yes |
| `Code/requirements.txt` | Pinned dependencies | Yes |
| `Dataset/` | 8 class folders, 23,328 images in total | No — download separately (e.g. GenImage) |

No script hardcodes an absolute path. `Code/paths.py` resolves the project root from its own location and supports environment-variable overrides:

| Content | Default | Override |
| --- | --- | --- |

| Feature cache | `~/ee5438_cache` | `EE5438_CACHE` |
| DINOv2 weights | `~/dinov2-large` | `EE5438_DINO` |

## 2. Environment

Tested with Python 3.9, an RTX 2080 (8 GB), CUDA 12.1, PyTorch 2.5.1.

```bash
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate

# CUDA 12.1 wheels; omit --index-url for a CPU-only install
python -m pip install torch==2.5.1 torchvision==0.20.1 \
  --index-url https://download.pytorch.org/whl/cu121

python -m pip install -r Code/requirements.txt
```

On first use, `open_clip` downloads the CLIP ViT-L/14 weights automatically (network required). Prepare the DINOv2 snapshot locally:

```bash
pip install huggingface_hub
huggingface-cli download facebook/dinov2-large --local-dir ~/dinov2-large
```

## 3. Data

Place eight class folders under `Dataset/`:

```
Dataset/
├── Nature/                    5,828 real images
├── ADM/                       2,500 images
├── BigGAN/                    2,500 images
├── glide/                     2,500 images
├── Midjourney/                2,500 images
├── stable_diffusion_v_1_5/    2,500 images
├── VQDM/                      2,500 images
└── wukong/                    2,500 images
```

Splits never move or copy files. Each image is assigned by hashing `seed:class/filename` with seed `5438` into 70/15/15 train/val/test buckets, so the split is identical on every machine. Verify the dataset with:

```bash
python Code/inspect_dataset.py
```

## 4. Full pipeline

```bash
python Code/run_pipeline.py --dry-run   # print every command without running it
python Code/run_pipeline.py             # run all stages in dependency order
```

This runs feature extraction → DINOv2 features → SVM / ResNet-18 baselines → linear probes → robustness, ablation and leave-one-generator-out evaluation → cross-validation → analysis → diagnostic figures → latency benchmark → web demo. All JSON results are written to `Results/final_v3/`.

| Stage | Script | Main output |
| --- | --- | --- |
| `audit` | `inspect_dataset.py` | dataset counts, formats, resolutions |
| `features` | `features.py` | `<cache>/<variant>.npz`: CLIP 768-d, ResNet-18 512-d, 24-d frequency descriptor |
| `dino` | `dino_features.py` | `<cache>/dino_<variant>.npz`: DINOv2 1024-d |
| `svm` | `svm_baseline.py` | `Results/final_v3/classical_svm_3gen/metrics.json` |
| `resnet` | `train_multi.py` | `Results/final_colab/final_multi_generator_frozen_10ep/metrics.json` |
| `probe` | `probe.py` | `Results/final_v3/main_lin/metrics.json` (P1 main comparison) |
| `robust` | `probe.py` | `main_robust/`, `aug_tta_dual/` (degradations and TTA) |
| `ablation` | `probe.py` | `Results/final_v3/ablation/metrics.json` (six representations) |
| `regime` | `probe.py` | `Results/final_v3/single_gen_dual/metrics.json` |
| `logo` | `probe.py` | `Results/final_v3/logo/<generator>/metrics.json` (7 folds) |
| `cv` | `cv_select.py` | `Results/final_v3/cv/cv_results.json` |
| `examples` | `make_example_grid.py` | real-vs-generated example figure |
| `analyze` | `analyze.py` | `Results/final_v3/summary.json` + evaluation figures |
| `assets` | `build_latex_assets.py` | `Results/final_v3/latex_assets.json` + diagnostic figures |
| `benchmark` | `benchmark.py` | `Results/final_v3/efficiency.json` |
| `demo` | `build_demo_page.py` | `Report/demo/index.html` |

Feature stages skip existing `.npz` files and the ResNet stage skips a completed run (`--force` retrains). To re-run only the probes after changing their configuration:

```bash
python Code/run_pipeline.py --stages probe robust ablation regime logo cv analyze assets benchmark demo
```

## 5. Training individual experiments

`run_pipeline.py` only sequences the scripts below; each is a standalone CLI.

### 5.1 Main comparison (UnivFD vs. DELP)

```bash
python Code/probe.py --cache ~/ee5438_cache --output Results/final_v3/main_lin \
  --train-generators stable_diffusion_v_1_5 BigGAN glide \
  --methods univfd dino_clip_lin \
  --max-val-per-generator 67 --max-eval-per-class 200
```

### 5.2 Leave-one-generator-out (example: hold out ADM)

```bash
python Code/probe.py --cache ~/ee5438_cache --output Results/final_v3/logo/ADM \
  --train-generators BigGAN glide Midjourney stable_diffusion_v_1_5 VQDM wukong \
  --methods univfd dino_clip_lin --max-val-per-generator 67 --max-eval-per-class 200
```

### 5.3 Representation ablation

```bash
python Code/probe.py --cache ~/ee5438_cache --output Results/final_v3/ablation \
  --train-generators stable_diffusion_v_1_5 BigGAN glide \
  --methods univfd dino_lin dino_clip_resnet_lin dino_clip_freq_lin dino_clip_lin dino_clip
```

### 5.4 Classical baseline (SVM)

```bash
python Code/svm_baseline.py --data Dataset --output Results/final_v3/classical_svm_3gen \
  --train-generators stable_diffusion_v_1_5 BigGAN glide --max-eval-per-class 200
```

### 5.5 ResNet-18 baseline (10 epochs, frozen backbone)

```bash
python Code/train_multi.py --data Dataset \
  --output Results/final_colab/final_multi_generator_frozen_10ep \
  --train-generators stable_diffusion_v_1_5 BigGAN glide --epochs 10 --batch-size 32 \
  --learning-rate 0.001 --max-train-per-generator 333 --max-val-per-generator 67 \
  --max-eval-per-class 200 --freeze-backbone
```

`--split-seed` must stay `5438`. `--aug` selects training degradations and `--tta` selects test-time averaging. On PowerShell, use `$env:USERPROFILE` instead of `~`; the scripts expand tilde on every platform.

## 6. Web demo

The demo server loads both frozen encoders, rebuilds the logistic probe from cached features with the same code as `probe.py`, and returns a real P(fake) for uploaded photos.

Prerequisites: the feature caches exist (run the `features` and `dino` stages) and the page has been generated (run the `demo` stage, or `python Code/build_demo_page.py`).

```bash
python Code/demo_server.py --port 8000            # opens the browser automatically
python Code/demo_server.py --port 8000 --no-open  # headless
```

Open **http://127.0.0.1:8000**. On start-up the console prints probe reconstruction details and the P1 unseen-generator accuracy (~95.9%). Drag, paste, or upload any photo to see the seven-stage animation and the measured P(fake) with timings. Without the server, opening `Report/demo/index.html` directly falls back to `offline` mode with pre-computed samples. Images are processed locally and never leave the machine.

## 7. Reproducibility

- Hash-based splits, fixed seed `5438`, validation-only checkpoint selection and a fixed logistic-regression configuration remove manual choices.
- Given the cached embeddings, `probe.py`, `analyze.py` and `build_latex_assets.py` are deterministic.
- GPU training of the ResNet-18 baseline is subject to standard floating-point nondeterminism; the shipped `metrics.json` is the measured run behind the reported numbers.
- The single-generator trainers (`train.py`, `train_aug.py`) and the early-stage helpers (`generate_dataset_figures.py`, `plot_results.py`) are kept for provenance and are not required by `run_pipeline.py`.

See `Code/README.md` for the detailed single-stage command list.
